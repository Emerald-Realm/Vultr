# Raven 1.7: First Production Release

Raven is a focused audiobook player built to make personal listening simple, reliable, and distraction-free. This first production release brings the core reading experience, persistent playback preferences, and a polished profile and settings experience together for everyday use.

## What's new

- Refined the Settings profile header and progress presentation.
- Added the supplied filled book, clock, and level icons with the correct colors.
- Improved profile avatar selection, including the external camera action.
- Reordered About settings so app version is shown last.
- Updated Terms of Service, Privacy Policy, and Open-Source License rows with external-link actions.
- Updated the Play release to version code 8.
- Confirmed Android 15 edge-to-edge support through AndroidX `enableEdgeToEdge()` and safe drawing insets.

## Distribution

- Play release artifact: `app-play-release.aab`
- Native debug symbols: `native-debug-symbols.zip`
